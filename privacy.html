Политика конфиденциальности расширения InitData Sniffer

Общая информация

Расширение InitData Sniffer предназначено для перехвата параметра initData из сетевых запросов к API сервера api.voxelplay.app с целью удобного использования этих данных пользователем в приложении.

Какие данные собираются

  • Расширение получает только параметр initData из запросов, направленных к указанному API.
  • Другие персональные данные пользователя не собираются и не обрабатываются.

Цель сбора данных

Полученные данные используются исключительно для отображения пользователю и облегчения работы с информацией внутри расширения.

Хранение данных

  • Все собранные данные хранятся локально в браузере пользователя с помощью механизмов расширений Chrome (chrome.storage).
  • Данные не передаются на сторонние серверы и не используются для любых внешних целей.

Права пользователя

  • Пользователь может в любой момент удалить расширение, что приведёт к автоматическому удалению всех локальных данных, связанных с расширением.
  • Расширение не сохраняет данные после своего удаления.
